# Disable Enemy Time Dilation for Caves of Qud

[![Steam Workshop](https://img.shields.io/badge/Steam-Workshop-blue)](https://steamcommunity.com/sharedfiles/filedetails/?id=3662847052)

A performance optimization mod that prevents NPCs from using the Time Dilation ability while allowing the player to continue using it.

## Why This Mod?

- **Performance**: When multiple NPCs use Time Dilation simultaneously, it can cause significant lag
- **Player Advantage Maintained**: You can still use Time Dilation normally
- **Cleaner Combat**: Reduces the complexity of multiple time effects in large battles

## What It Does

- Blocks all NPCs and enemies from activating Time Dilation
- Player character can still use Time Dilation without restrictions
- No impact on other abilities or game mechanics

## Installation

### Via Steam Workshop (Recommended)

[Subscribe on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3662847052)

### Manual Installation

1. Download or copy the `DisableEnemyTimeDilation` folder to your Caves of Qud mods directory:
   - **Linux**: `~/.config/unity3d/Freehold Games/Caves of Qud/Mods/`
   - **Windows**: `%USERPROFILE%\AppData\LocalLow\Freehold Games\Caves of Qud\Mods\`
2. Launch Caves of Qud and enable the mod in the mod manager

## Compatibility

- Safe to add to existing saves
- Safe to remove (enemies will regain ability to use Time Dilation)
- Compatible with other mods
- Works with modded creatures that have Time Dilation

## Performance Impact

Positive - reduces lag from multiple Time Dilation activations in combat.
