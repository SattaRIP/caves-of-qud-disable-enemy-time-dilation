# Disable Enemy Temporal Fugue for Caves of Qud

A performance optimization mod that prevents NPCs from using the Temporal Fugue ability while allowing the player to continue using it.

## Why This Mod?

- **Performance**: When multiple NPCs use Temporal Fugue simultaneously, it can cause significant lag
- **Player Advantage Maintained**: You can still use Temporal Fugue normally
- **Cleaner Combat**: Reduces the chaos of multiple time clones in large battles

## What It Does

- Blocks all NPCs and enemies from activating Temporal Fugue
- Player character can still use Temporal Fugue without restrictions
- No impact on other abilities or game mechanics

## Installation

### Via Steam Workshop (Recommended)

[Subscribe on Steam Workshop](#) *(Coming Soon)*

### Manual Installation

1. Download or copy the `DisableEnemyTemporalFugue` folder to your Caves of Qud mods directory:
   - **Linux**: `~/.config/unity3d/Freehold Games/Caves of Qud/Mods/`
   - **Windows**: `%USERPROFILE%\AppData\LocalLow\Freehold Games\Caves of Qud\Mods\`
2. Launch Caves of Qud and enable the mod in the mod manager

## Compatibility

- Safe to add to existing saves
- Safe to remove (enemies will regain ability to use Temporal Fugue)
- Compatible with other mods
- Works with modded creatures that have Temporal Fugue

## Performance Impact

Positive - reduces lag from multiple Temporal Fugue activations in combat.
